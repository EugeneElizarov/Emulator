# Эмулятор физиологических параметров

Прошивка устройства для эмуляции физиологических сигналов человека. По текущему описанию проекта целевые параметры — пульс и кожно-гальваническая реакция (КГР / GSR).

## Аппаратная платформа и инструменты

- MCU: STM32F303CCT6 (STM32F303CCTx, Cortex-M4, корпус LQFP48).
- IDE / сборка: Keil MDK-uVision; в конфигурации CubeMX указан MDK-ARM V5.32.
- Конфигурация периферии: STM32CubeMX 6.14.0, STM32Cube FW_F3 V1.11.6.
- Основные файлы проекта:
  - `HR_Emulator.ioc` — конфигурация STM32CubeMX.
  - `MDK-ARM/HR_Emulator.uvprojx` — проект Keil uVision.
  - `MDK-ARM/startup_stm32f303xc.s` — startup-файл.
  - `Core/` — код приложения и конфигурация периферии.
  - `Drivers/` — CMSIS и STM32F3 HAL/LL.

## Текущее состояние исходников

На текущем этапе `main.c` выполняет базовую инициализацию HAL, тактирования, GPIO, ADC1, DAC и USB PCD. Основной цикл пока пустой. Алгоритмы формирования пульса и КГР, а также прикладной USB-протокол в текущем снимке исходников не реализованы.

Настройки периферии, зафиксированные в исходниках:
- ADC1: один 12-битный программно запускаемый канал ADC1_IN1 на PA0.
- DAC: канал 1 на PA4, выходной буфер включён.
- USB: Full Speed Device, встроенный PHY, PA11 (DM), PA12 (DP).
- GPIO: кнопка KEY, индикаторы LED, сигналы HV_EN и HEAT_ON, линии GSRb0…GSRb11. Точные назначения и режимы см. в `Core/Inc/main.h`, `Core/Src/gpio.c` и `HR_Emulator.ioc`.

Текущая конфигурация тактирования в проектных файлах: HSE 8 МГц, SYSCLK 72 МГц. Перед изменением частот необходимо сверить фактический установленный кварц/генератор и требования USB.

## Сборка

Откройте `MDK-ARM/HR_Emulator.uvprojx` в Keil MDK-uVision и соберите target `HR_Emulator`. Для воспроизводимой сборки требуется совместимая версия Keil/Arm Compiler и установленные компоненты STM32F3.

Сборка и проверка на целевом устройстве в рамках подготовки этого репозитория не выполнялись.
